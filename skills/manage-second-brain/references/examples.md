# Examples

## Customer learning

Preserve the original interview or note. Record exact language, observed behavior, source/date, confidence, business implication, contradiction, and next test. Update a customer page only when evidence changes it.

## Decision

Record context, options, evidence, assumptions, owner, reversibility, rationale, risks, review date, and follow-up evidence. Represent a reversal as a linked new decision.

## Query

For “What did we decide about pricing?”, search decisions first, then relevant business, customer, project, and daily pages. Report freshness, uncertainty, and any superseding decision.

## Binary asset

Store the payload only under the repository-level dated `assets/` convention plus `<filename>.metadata.md`. Under `second-brain/raw/<source-id>/`, create a textual source record linking the asset, sibling metadata, and stable privacy-safe backup locator. Never duplicate the payload under raw.
