# Retrieval and Synthesis

Retrieve before claiming knowledge about prior decisions, preferences, commitments, customers, or results.

1. Start at `second-brain/wiki/index.md`.
2. Follow one relevant category or map page.
3. Search exact names, aliases, dates, and phrases.
4. Broaden to full-text or hybrid search only when exact routing fails.
5. Read canonical pages and the source pages needed to verify important claims.
6. Check dates, confidence, contradictions, validity windows, and superseding records.
7. Answer with file or source references and separate fact, user statement, inference, hypothesis, and recommendation.
8. Save the result under `outputs/` only when reusable; integrate durable conclusions into canonical pages.

Absence from memory is not evidence that something did not happen.
