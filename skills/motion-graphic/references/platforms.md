# Platform presets

Defaults to recommend when asking. Platform specs change — if a decision depends on an exact limit, verify against the platform's current help pages.

| Platform / placement | Ratio | Resolution | Recommended length | Notes |
|---|---|---|---|---|
| Instagram Reels | 9:16 | 1080×1920 | 15–30s | Keep text out of bottom ~20% and top ~14%; right edge has action buttons |
| Instagram feed video | 4:5 | 1080×1350 | 15–30s | Ask Reels vs feed when user says only "Instagram" |
| Instagram / Facebook Stories | 9:16 | 1080×1920 | ≤15s per segment | Top/bottom UI overlays |
| TikTok | 9:16 | 1080×1920 | 15–45s | Caption and buttons cover bottom/right |
| YouTube Shorts | 9:16 | 1080×1920 | 15–45s | Similar safe zones to Reels |
| YouTube (long-form / embed) | 16:9 | 1920×1080 | per content | Title-safe margins 5% |
| LinkedIn feed | 4:5 (recommended) or 1:1; 16:9 for presentations | 1080×1350 / 1080×1080 / 1920×1080 | 30–60s | Mostly muted viewing → burned-in captions mandatory; professional tone |
| Facebook feed | 4:5 or 1:1 | 1080×1350 / 1080×1080 | 15–45s | Muted autoplay → captions |
| X (Twitter) | 16:9 or 1:1 | 1920×1080 / 1080×1080 | 15–45s | |
| Website hero / landing | 16:9 | 1920×1080 | 8–20s loop | Usually no voiceover; seamless loop |
| WhatsApp status | 9:16 | 1080×1920 | ≤30s | |

## Universal rules

- 30fps, H.264 MP4, AAC audio, yuv420p, `+faststart`.
- Hook within the first 1.5s; the core message must be readable with sound off.
- Captions: burned in, Hebrew RTL, max 2 lines, high contrast, inside safe zone.
- End card with CTA held ≥2.5s.
- When the user names several platforms, propose one master ratio + the reframes needed (e.g. 9:16 master, 4:5 reframe for LinkedIn) and confirm before rendering more than one.
