# Select Business Playbook

This is a generic capability skill, not an employee or named worker. Do not invent a person or employee identity for it.

1. Read `GOAL.md` and state its measurable gap, deadline, and current constraint or decision.
2. Locate the playbook routing index, defaulting to `playbooks/index.md`. If it is absent, search for a repository playbook index; if none exists, report that smallest blocker and do not invent a library.
3. Search the index's titles, summaries, shelves, and selection guidance before opening any playbook file.
4. Shortlist at most three candidates. Rank them with [selection rubric](references/selection-rubric.md).
5. Open only the strongest primary playbook. Add one supporting playbook only when a named dependency requires it.
6. Check triggers, `do_not_use_when`, required inputs, stage, evidence strength, gates, metrics, and guardrails.
7. Produce an [execution brief](references/execution-brief.md) adapted to current evidence and authority.
8. Cite selected file paths and distinguish playbook guidance from project facts.

Do not load an entire shelf, recursively open linked sources, or stack frameworks without a decision-relevant reason.
