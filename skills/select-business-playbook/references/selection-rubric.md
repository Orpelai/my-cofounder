# Selection Rubric

Select for the current constraint, not for general resemblance.

Score each candidate from 0–2:

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Goal leverage | Indirect | Helpful | Directly attacks gap |
| Trigger fit | Weak | Partial | Explicit |
| Evidence fit | Inputs absent | Some inputs | Required inputs available |
| Time fit | Too slow | Adaptable | Fits deadline |
| Actionability | Generic | Some gates | Clear next action |
| Learning value | Little | Useful | Resolves key uncertainty |

Disqualify a candidate when a `do_not_use_when` condition applies, a required safety gate cannot be met, or the method conflicts with authority boundaries.

Prefer one primary playbook. Add a supporting playbook only when it supplies a missing capability the primary playbook explicitly needs. Record why close alternatives were not selected.
