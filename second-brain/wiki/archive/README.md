# Archive Shelf

Superseded or inactive derived knowledge that remains useful for history belongs here. Use the [compact/archive operation](../../operations/compact-archive.md) for every transition.

## Retained partitions

- `logs/YYYY/YYYY-MM.md` — digest-verified closed-month Second Brain operation entries.
- `logs/routines/YYYY/YYYY-MM.md` — material routine-log partitions copied from the append-only root routine log without modifying it.
- `weekly/YYYY/YYYY-Www.md` — evidence-linked weekly summaries and explicit revisions.
- `actions/YYYY/YYYY-MM.md` — terminal action snapshots with stable IDs, action hashes, attempts, final evidence, and archive transition state.
- `pages/<original-wiki-relative-path>` — archived derived pages with reason, date, replacement, and recovery path.

Create directories and index links only when the first retained record exists; do not prefill empty history.

## Transition rules

Extract every unresolved commitment into the [canonical action register](../actions/register.md) before archiving a meeting-linked output or another derived page. Verify source links, archive count and digest, and a recovery link before removing current routing. A terminal action remains in the current register for seven complete days before its verified snapshot moves here.

Consolidation may summarize repeated no-op state, but it does not erase source entries. Raw evidence is never archived by moving, rewriting, compacting, or deleting it. Decision history, metric observations, attempts, meeting minutes, source references, and archive snapshots remain recoverable.
