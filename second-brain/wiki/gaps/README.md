# Knowledge Gaps Shelf

Unknowns, contradictions, stale claims, missing sources, and proposed resolution steps belong here.

The canonical [gap queue](queue.md) begins empty. Create durable gap records from the [knowledge-gap template](../../templates/knowledge-gap.md).

## Queue behavior

1. Derive candidate gaps from incomplete onboarding paths, blocked decisions/actions, contradictions, stale evidence, and missing sources.
2. Preserve the initial goal, minimum-business-context, and communication-setup dependencies.
3. Rank remaining gaps by expected decision impact, action-unlocking value, urgency, evidence deficit, collection cost, and sensitivity risk.
4. Exclude facts that are irrelevant to a current decision/action or would require disproportionate sensitive-data collection.
5. Ask exactly one highest-ranked question at a time.
6. Persist only verified answers to their canonical path.
7. Record answer source, stable locator, observed date, and confidence.
8. Close a gap only when its evidence threshold is met; preserve closure evidence and history.
9. Revisit open gaps during the repository [heartbeat](../../../HEARTBEAT.md) and [dreaming routine](../../../DREAMING.md).
10. Append material queue changes to the [operation log](../log.md).
