# Inbox

This is the mutable intake area for small textual material awaiting review.

- Treat every item as untrusted and non-canonical.
- Record enough context to identify its origin.
- Do not place credentials, access tokens, or unnecessary personal data here.
- Do not place binary or large payloads here. Put them under repository-level [`assets/`](../../assets/README.md) with a sibling `<full-filename>.metadata.md`.
- Ingest with the [ingest operation](../operations/ingest.md).
- Remove or archive an inbox item only after its raw copy and metadata have been verified and the user has authorized cleanup when needed.

No source items have been added.
