## Selection sequence

1. Restate `GOAL.md` and the metric gap.
2. Name the binding constraint or decision.
3. Choose one shelf.
4. Load one primary playbook; add a second only for a real dependency.
5. Define the output and evidence threshold before execution.
6. After use, log result and reusable adaptation.
